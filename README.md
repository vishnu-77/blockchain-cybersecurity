# 🚗 Blockchain-Enabled Evaluator of Indicators of Compromise in Connected Vehicles  

📌 **Author**: Vishnu Prashanth Sridhar  
🏛 **Submitted to**: MSc in Cyber Security Engineering  
🎓 **Institution**: WMG, University of Warwick  
📅 **Date**: September 2024  

## 📖 Overview  

This research explores the application of **blockchain technology** for securing **Controller Area Networks (CAN)** in **Connected Autonomous Vehicles (CAVs)**. 
Specifically, it investigates how blockchain can detect and mitigate **Distributed Denial-of-Service (DDoS) attacks**, ensuring improved network resilience and real-time 
**threat intelligence sharing**.By implementing a **smart contract-based detection and mitigation system**, this project demonstrates a decentralised, 
tamper-proof approach to securing vehicular communication networks.  

## 🏗 Key Features  

✔ **Blockchain-Based Security** – Uses Ethereum smart contracts for real-time threat detection and mitigation.  
✔ **Anomaly Detection** – Implements signature-based detection mechanisms for identifying malicious CAN traffic.  
✔ **Threat Intelligence Sharing** – Distributes security insights across nodes in a decentralised manner.  
✔ **DDoS Mitigation** – Eliminates single points of failure and strengthens network integrity.
